## Objectives  
- Preprocess and scale features to ensure consistent model input.  
- Train multiple machine learning models including Logistic Regression, Decision Tree, Random Forest, K-Nearest Neighbors, Naive Bayes, and Support Vector Machine.  
- Evaluate model performance using accuracy, classification reports, and confusion matrices.  
- Visualize results to compare model effectiveness and identify the best performing algorithms.

---

## Tools & Techniques  
- **Python** with pandas and NumPy for data handling.  
- **Scikit-learn** for machine learning algorithms and model evaluation.  
- **Matplotlib** and **Seaborn** for data visualization.  
- Emphasis on data scaling, train/test splitting, and performance comparison across multiple models.

---

## Key Insights  
- Random Forest and Support Vector Machine models performed best for this dataset in terms of accuracy.  
- Confusion matrices helped identify which classes were predicted most accurately and where misclassifications occurred.  
- Comparing models side-by-side provided insight into algorithm selection based on dataset characteristics.
